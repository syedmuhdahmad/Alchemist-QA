# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep criticism about the work. Harassment and personal attacks are not accepted in issues, pull requests, discussions, or any other project space.

## Reporting

Report a problem privately to the maintainer through [GitHub](https://github.com/syedmuhdahmad). Reports are kept confidential. The maintainer will review each report and may warn, temporarily ban, or permanently ban a participant, following the enforcement guidelines in the Contributor Covenant.
